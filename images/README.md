# Photos

Drop your own pictures here, keeping the same file names:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`

The files currently in this folder are elegant placeholders — just overwrite them.

Want different captions, more photos or fewer? Edit the `photos` array in
`src/data/site.ts`.
